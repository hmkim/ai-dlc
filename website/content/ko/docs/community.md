### Han 에코시스템

AI-DLC는 Claude Code용 플러그인 마켓플레이스인 Han의 일부입니다:

- **웹사이트:** [han.guru](https://han.guru)
- **Core:** 기반 플러그인 및 품질 원칙
- **Validation:** 언어 및 도구 유효성 검사 훅
- **Frameworks:** 프레임워크별 플러그인 (React, Next.js, Rails 등)
- **Languages:** 언어별 플러그인 (TypeScript, Go, Rust 등)
- **Disciplines:** 전문 에이전트 플러그인 (프론트엔드, 백엔드, 보안 등)
- **Bridges:** MCP 서버 통합
- **Bushido:** 품질 원칙 및 엔지니어링 덕목

## 감사의 말

AI-DLC는 다음 분들의 작업을 기반으로 합니다:

- **Raja SP (AWS)** - 원본 AI-DLC 방법론
- **Geoffrey Huntley** - Ralph Wiggum technique
- **Boris Cherny & Anthropic** - 프로덕션 구현 패턴
- **Steve Wilson (OWASP)** - HITL/HOTL 거버넌스 프레임워크
- **HumanLayer** - 12 Factor Agents 원칙
- **The Claude Code 커뮤니티** - 피드백 및 실제 환경 테스트

AI-DLC를 발전시키는 데 도움을 주신 모든 기여자분들께 감사드립니다.
